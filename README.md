# henge（ヘンゲ）

円・縦長・横長の3つの形に切り替えながら進む、iOS 向けのアクションゲームです。

- App Store：[ヘンゲ](https://apps.apple.com/app/id6759702304)
- 言語：Swift（SpriteKit）
- 開発ツール：Xcode

## 遊び方

画面左下の十字キーで移動し、右下の「change」ボタンで形を切り替えます。全10ステージで、制限時間内にゴールを目指します。

| 形 | 特徴 |
|---|---|
| 円 | 基本の形 |
| 縦長 | 狭い縦の隙間を通れる |
| 横長 | 低い天井の下を通れる |

## ギミック

- 動く壁：隙間が開くタイミングに合わせて形を変えて通る
- 追跡者：プレイヤーに近づいてくる敵
- クランクゲート：決まった形でしか通れない通路
- コイン：各ステージに1枚ずつ置いてある

## 公開まで

App Store の審査で何度もリジェクトされました。内容と紹介文を作り直して公開しています。

## コードの構成

SpriteKit で作っています（Xcode のプロジェクト名は `moving`）。

| ファイル | 役割 |
|---|---|
| `moving/GameScene.swift` | ゲームの本体。プレイヤーの変形・移動・当たり判定と、壁や敵などのギミックを作る関数（動く壁、追跡者、クランクゲートなど） |
| `moving/StageProtocol.swift` | 全ステージが従う共通の型（制限時間と、ステージを組み立てる処理） |
| `moving/Stage1.swift` 〜 `Stage10.swift` | 各ステージで、どのギミックをどこに置くか |
| `moving/StageSelectScene.swift` | ステージ選択画面、進み具合の表示とリセット |

ギミックは本体に関数としてまとめ、ステージのファイルはそれを呼んで並べるだけにしています。新しいステージは、共通の型に合わせたファイルを1つ足せば作れます。
